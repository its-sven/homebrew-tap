# its-sven/homebrew-tap

Homebrew casks for my macOS apps.

```bash
brew install --cask its-sven/tap/drivedock
```

| Cask | App |
|---|---|
| `drivedock` | [DriveDock](https://github.com/its-sven/DriveDock) – keeps SMB and WebDAV shares mounted in Finder |

The casks are updated automatically when a new release is published.
